# حاسبة قطة النزهة

تطبيق بسيط لحساب قطة نزهة تمتد عدة أيام بين عدة عوائل، ويعمل بدون إنترنت بعد أول فتح.

## المزايا
- طريقتان للتقسيم:
  - **بالفرد:** إجمالي المصروف ÷ مجموع (أفراد كل عائلة × أيام حضورها)، مع خيار احتساب الطفل بنصيب كامل أو نصف أو ربع أو إعفائه.
  - **بالعائلة:** حصص متساوية لكل عائلة بغض النظر عن عدد أفرادها، وتقل الحصة إن حضرت العائلة أياماً أقل.
- تسجيل كل مبلغ دفعه رب الأسرة مع البند واليوم.
- تقرير يبيّن نصيب كل عائلة وما دفعته والصافي (له / عليه).
- تسوية تلقائية بأقل عدد من التحويلات (من يحوّل لمن وكم).
- نسخ التقرير للواتساب، ونسخة احتياطية واسترجاع.
- البيانات محفوظة على الجهاز نفسه.

## التشغيل
فعّل GitHub Pages من Settings ← Pages ← Branch: `main` / root، ثم افتح الرابط:
`https://alaapro33.github.io/trip-split/`

## التحويل إلى APK
1. افتح https://www.pwabuilder.com وضع رابط GitHub Pages أعلاه.
2. اختر **Package for stores ← Android** ثم **Download**.
3. ستجد داخل الملف المضغوط ملف `.apk` جاهزاً للتثبيت على الجوال.
